# Archive

Superseded material, kept for provenance and not used by the Applied Energy
wake-loss manuscript.

Two groups:

* **Thesis-era runs** (`thesis-*`), which predate the paper's harmonised
  scenario grid.
* **Pre-fix paper runs**, produced before commit `e70024f6` made `mesh_region`
  honour the area threshold as a strict maximum. Those runs treated the
  threshold as a target mean, so 30-45% of subregions exceeded it. The
  manuscript reports the post-fix runs, which now carry the canonical names in
  the parent directory.

Nothing here is referenced by the manuscript, its figures, or the
configurations under `config/pypsa-wake/`.
